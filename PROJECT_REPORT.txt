1. Project Overview
-------------------
This project is a government-focused Human Resource Management System (HRMS) with attendance, leave, overtime, payroll, ministry, and employee management modules. It is split into two main parts:
- Frontend: React + Vite
- Backend: Laravel 11 + SQLite + Sanctum

2. Architecture Summary
-----------------------
Frontend Stack:
- React 18
- React Router DOM
- TanStack React Query
- Vite
- Lucide icons

Backend Stack:
- Laravel 11
- SQLite database
- REST API routes
- Policies and middleware
- Eloquent models and migrations

3. Main Project Locations

Root Files:
- package.json: root frontend package config

Backend Source:
- backend/app/Http/Controllers/Api/: API controllers
- backend/app/Models/: Eloquent models
- backend/database/migrations/: DB schema definitions

- backend/routes/api.php: API route definitions
